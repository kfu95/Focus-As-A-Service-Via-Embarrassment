Permissions

      

        Allow Jail Helper to control Messages under System Settings → Privacy
        & Security → Automation. Allow Shortcuts to send messages when
        prompted. Cancelled or denied prompts keep Jail locked.
      

      

        Only “Pick from Mac Contacts” requests Contacts access. Allow Jail
        Helper under Privacy & Security → Contacts. You can use contact
        cards instead.
      

      

        Sign in to Messages. Non-iMessage (green bubble) recipients need an
        iPhone with Text Message Forwarding enabled for this Mac and a carrier
        supporting group MMS/RCS. If a recipient cannot join the group, sending
        fails and Jail stays locked.
      

      

        Before relying on Jail, run a manual trial with two consenting people.
        Automated tests never send texts.
